    How it works

    From a single sentence to shipped work.

    Every AgentPals agent runs the same loop — the one great teammates already use.

    1. 01

      Understand

      Describe the goal in plain language. AgentPals reads the context it needs — docs, tickets, data — and clarifies anything ambiguous.

    2. 02

      Plan

      A planner agent breaks the goal into steps and assigns each to a specialist: researcher, analyst, writer, engineer.

    3. 03

      Act

      Agents call real tools — APIs, browsers, code sandboxes — and pause for your approval on anything sensitive.

    4. 04

      Verify & learn

      A reviewer agent checks the output against your criteria. Every run makes the next one smarter.

    FAQ

    Questions, answered.

    What is "multiplayer AI"?

    Most AI today is single-player: one person, one private chat, and answers that never reach the rest of the team. Multiplayer AI puts humans and agents in one shared space. Everyone sees the same context, decisions and results, so work is done once, hand-offs disappear, and every resolution becomes knowledge the whole team can build on.

    Can agents really work on production systems?

    Yes, within guardrails you define. Agents can read logs, metrics and traces, run diagnostics and prepare fixes or rollbacks. Anything that changes production waits for a human approval in the shared room, and every action is recorded in the audit trail.

    What is an "agentic" AI?

    Instead of answering one prompt, an agent pursues a goal: it plans steps, uses tools, checks its own work and keeps going until the task is done — or until it needs you.

    Will agents take actions without my permission?

    Only the ones you allow. You decide which actions run automatically and which require a human approval, per agent and per tool.

    Where does my data go?

    Your data is used only to complete your tasks. Private deployment is available, so your data never has to leave your environment.

    Do I need to write code?

    No. Describe the work in plain language. Developers can also use our API and SDK for deeper customization.
